RNGMVERSE — Website for novelist Weiz Orina

This folder is a complete production website. Upload its contents (not the
folder itself) to the root directory of any static web host, such as Netlify,
Vercel, GitHub Pages, or your web-hosting provider.

The home page is index.html. The assets and books folders are required and
must remain alongside it.

The site includes the four supplied cover artworks:
  • April's Full
  • North Atlantic Challenge
  • The Globetrotter
  • Meltn Savana
